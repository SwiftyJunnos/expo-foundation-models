# CoreML

Run custom CoreML models from your app bundle.

## Overview

CoreML enables running custom machine learning models on-device for:
- Image classification
- Object detection
- Natural language processing
- Custom predictions

## Requirements

- **iOS 16.0+**
- CoreML model in app bundle (`.mlmodelc`)

## Adding Models to Your App

### 1. Add Model to Xcode Project

1. Drag your `.mlmodel` or `.mlpackage` file into Xcode
2. Ensure it's added to your app target
3. Xcode compiles it to `.mlmodelc` automatically

### 2. Model File Types

| Format | Description |
|--------|-------------|
| `.mlmodel` | Single model file |
| `.mlpackage` | Model package (recommended) |
| `.mlmodelc` | Compiled model (generated by Xcode) |

## Basic Usage

### Loading a Model

```typescript
import { CoreML } from 'expo-foundation-models';

// Load model from app bundle
const modelId = await CoreML.loadModel('MyClassifier');

console.log('Model loaded:', modelId);
```

### Running Predictions

```typescript
const result = await CoreML.predict(modelId, {
  // Input features depend on your model
  inputImage: imageData,
  // or
  inputFeatures: [1.0, 2.0, 3.0, 4.0],
});

console.log('Prediction:', result);
// { classLabel: "cat", classProbabilities: { cat: 0.95, dog: 0.05 } }
```

### Unloading Models

```typescript
await CoreML.unloadModel(modelId);
```

## Model Management

### Check if Loaded

```typescript
const isLoaded = CoreML.isModelLoaded(modelId);

if (!isLoaded) {
  modelId = await CoreML.loadModel('MyClassifier');
}
```

### Get All Loaded Models

```typescript
const models = CoreML.getLoadedModels();

console.log('Loaded models:', models);
// ["MyClassifier_abc123", "ObjectDetector_def456"]
```

## Error Handling

```typescript
import { CoreML, CoreMLError } from 'expo-foundation-models';

try {
  const modelId = await CoreML.loadModel('NonexistentModel');
} catch (error) {
  if (error instanceof CoreMLError) {
    console.error('CoreML Error:', error.message);
    console.error('Code:', error.code);
    // Codes: LOAD_FAILED, PREDICTION_FAILED, etc.
  }
}
```

## Complete Example

### Image Classifier

```typescript
import { useState, useEffect } from 'react';
import { CoreML, CoreMLError } from 'expo-foundation-models';
import * as ImagePicker from 'expo-image-picker';

function ImageClassifier() {
  const [modelId, setModelId] = useState<string | null>(null);
  const [result, setResult] = useState<any>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    // Load model on mount
    CoreML.loadModel('ImageClassifier')
      .then(setModelId)
      .catch((e) => setError(e.message));

    // Cleanup on unmount
    return () => {
      if (modelId) {
        CoreML.unloadModel(modelId);
      }
    };
  }, []);

  const classifyImage = async () => {
    if (!modelId) return;

    try {
      // Pick image
      const result = await ImagePicker.launchImageLibraryAsync({
        mediaTypes: ImagePicker.MediaTypeOptions.Images,
        base64: true,
      });

      if (result.canceled) return;

      // Run prediction
      const prediction = await CoreML.predict(modelId, {
        image: result.assets[0].base64,
      });

      setResult(prediction);
    } catch (e) {
      if (e instanceof CoreMLError) {
        setError(e.message);
      }
    }
  };

  return (
    <View>
      <Button title="Classify Image" onPress={classifyImage} />
      {result && <Text>Result: {JSON.stringify(result)}</Text>}
      {error && <Text>Error: {error}</Text>}
    </View>
  );
}
```

### Numeric Prediction

```typescript
async function predictPrice(features: {
  sqft: number;
  bedrooms: number;
  bathrooms: number;
  yearBuilt: number;
}) {
  const modelId = await CoreML.loadModel('HousePricePredictor');
  
  try {
    const result = await CoreML.predict(modelId, {
      squareFootage: features.sqft,
      numberOfBedrooms: features.bedrooms,
      numberOfBathrooms: features.bathrooms,
      yearBuilt: features.yearBuilt,
    });
    
    return result.predictedPrice;
  } finally {
    await CoreML.unloadModel(modelId);
  }
}
```

## Model Caching

Manage multiple models efficiently:

```typescript
class ModelCache {
  private models: Map<string, string> = new Map();

  async getModel(name: string): Promise<string> {
    if (this.models.has(name)) {
      return this.models.get(name)!;
    }

    const modelId = await CoreML.loadModel(name);
    this.models.set(name, modelId);
    return modelId;
  }

  async unloadAll(): Promise<void> {
    for (const modelId of this.models.values()) {
      await CoreML.unloadModel(modelId);
    }
    this.models.clear();
  }
}

const cache = new ModelCache();

// Usage
const modelId = await cache.getModel('MyClassifier');
const result = await CoreML.predict(modelId, input);
```

## Best Practices

1. **Load once, use many** - Don't reload models for each prediction
2. **Unload when done** - Free memory for unused models
3. **Handle errors** - Models may fail to load or predict
4. **Check platform** - CoreML is iOS-only
5. **Optimize models** - Use Core ML Tools to quantize/optimize

## Performance Tips

- **Compile models** - Use compiled `.mlmodelc` format
- **Reduce precision** - Quantize to float16 or int8
- **Batch predictions** - Group multiple inputs when possible
- **Background loading** - Load models before they're needed
